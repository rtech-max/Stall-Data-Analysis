Stall Data Analysis Using SQL

Project Overview

This project focuses on analysing stall exhibition data using SQL. It demonstrates basic SQL queries and data analysis techniques to extract useful information from the dataset.

Tools Used

- SQLite
- DB Fiddle
- GitHub

SQL Concepts Covered

- SELECT and DISTINCT
- WHERE and LIKE
- AND and OR
- IN operator
- COUNT function
- GROUP BY and HAVING
- ORDER BY
- Subqueries

Project Files

- "schema.sql" – Contains database table creation and sample data.
- "queries.sql" – Contains SQL queries used for data analysis.

Project Objectives

- Understand and organise stall data.
- Retrieve specific records.
- Count total and unique stalls.
- Group and sort records.
- Perform basic data analysis.

Conclusion

This project helped me understand SQL fundamentals and apply database queries to a practical data analysis task.# Stall-Data-Analysis
