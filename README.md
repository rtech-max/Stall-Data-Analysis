Stall Data Analysis

Project Overview

Stall Data Analysis is a beginner-level Data Analytics project based on the stall exhibition of RONAK 2K26. The project focuses on analyzing stall performance using data related to visitors, units sold, revenue, expenses, and profit.

The main purpose of this project is to understand how data analytics tools can help analyze business performance and generate useful insights.

Objectives

- To analyze stall-wise performance.
- To understand revenue, expenses, and profit.
- To compare the performance of different stalls.
- To identify useful patterns and insights from the dataset.
- To practice SQL and Python for data analysis.

Dataset Description

The dataset contains information about different stalls, including:

- Stall Name
- Visitors
- Units Sold
- Revenue
- Expenses
- Profit

Tools and Technologies Used

- Google Sheets: Data organization and visualization.
- SQL (SQLite): Data querying and analysis using DB Fiddle.
- Python: Data analysis and visualization.
- GitHub: Project storage and documentation.

Project Workflow

1. Dataset Creation

Created a dataset containing stall-wise information such as visitors, units sold, revenue, expenses, and profit.

2. Google Sheets Analysis

Organized the dataset in Google Sheets and created graphs to visualize revenue and profit. Also prepared project insights.

3. SQL Analysis

Used DB Fiddle with SQLite to write and execute SQL queries.

SQL concepts used include:

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT and DISTINCT
- AND, OR and IN
- HAVING
- Aggregate Functions
- Subqueries
- CASE WHEN

4. Python Analysis

Used Python to perform data analysis and create visualizations from the stall dataset.

5. Dashboard and Insights

Prepared a PDF containing the project data, revenue and profit graphs, and project insights.
